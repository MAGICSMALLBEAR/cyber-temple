# 賽博虛擬神殿 3D

以台灣廟宇參拜文化為題材的瀏覽器 3D 作品：在廟埕與大殿裡走動，點香、擲筊、求籤、擺供、點光明燈，也有每日功課、農曆節慶與天氣變化。不用安裝，打開網頁就能玩，手機可加到主畫面離線使用。

**線上試玩：** https://magicsmallbear.github.io/cyber-temple/

> 線上版是單機版：進度只存在你的瀏覽器，沒有多人同行。多人功能需要在自己的電腦執行伺服器（見下方「在自己電腦執行」）。

## 怎麼玩

| 操作 | 電腦 | 手機 |
| :--- | :--- | :--- |
| 走動 | WASD／方向鍵 | 左下搖桿 |
| 轉視角 | 滑鼠左鍵拖曳 | 右半邊螢幕拖曳 |
| 和附近物件互動 | E | 點畫面上的互動按鈕 |
| 敲木魚／擲筊 | 空白鍵 | 點按鈕 |
| 鏡頭回到身後 | C | — |
| 所有功能清單（萬寶閣） | Tab | 點「萬寶閣」 |
| 全部快捷鍵 | ? | 點 ❓ |

第一次進來會有四步新手引導：點香 → 擲筊 → 求籤 → 讀籤。

## 主要內容

- **大殿參拜**：點香、擲筊、正統三步求籤（六十甲子籤）、本地或 Gemini AI 解籤、八步完整參拜流程
- **供品**：供品鋪、擺供與敬獻、還願紀錄
- **八尊神尊**：媽祖、文昌帝君、五路財神、月下老人、觀世音菩薩、關聖帝君、土地公，以及本站原創的「綠燈星君」
- **修行**：每日簽到與功課、農曆節慶、二十四節氣、念珠、禪修、抄經、成就與功德護照
- **環境**：時辰天色、模擬或真實天氣（Open-Meteo）
- **平台**：PWA 離線、畫質自動調整、字級與減少動態、鍵盤與螢幕閱讀器支援、VR（WebXR）

## 在自己電腦執行

需要 [Node.js](https://nodejs.org/)（建議 24 版）。

```
npm start
```

然後開 http://localhost:8080 。Windows 也可以直接雙擊 `啟動神殿.bat`。同一個 WiFi 下的手機與平板連到這台電腦的 IP，就能一起多人同行。

不執行伺服器、直接開 `index.html` 也能玩，但沒有多人功能與離線快取。

## 測試

```
npm test          # 輕量檢查，約 10 秒，不開 3D 瀏覽器
npm run test:full # 完整測試，需安裝 Playwright，約 20–30 分鐘，請在本機執行
```

GitHub Actions 每次推送只跑輕量檢查；完整測試在本機跑。細節見 [tests/README.md](tests/README.md)。
