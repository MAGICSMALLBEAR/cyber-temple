# 真機驗收清單

自動化測試在沒有顯示卡、沒有喇叭的環境跑，以下項目只能用真的電腦和手機確認。每項打勾，有問題就在後面寫下看到什麼。

**準備：** 用「啟動神殿.bat」開啟（不要直接點 index.html，否則多人連線與離線功能不會啟用）。

## 一、電腦（建議先清除本站資料，模擬新玩家）

**開場與畫面**
- [ ] 第一次開啟出現操作導引，關閉後重新整理不再出現
- [ ] 開場看得到自己的分身、神案與香爐，畫面沒有被大塊物體擋住
- [ ] 右上「視角」按鈕、頂部按鈕列、飄過的彈幕三者沒有互相遮住（把視窗拉窄再看一次）
- [ ] 天空、地板、柱子沒有破圖、閃爍或全黑
- [ ] 走路撞到牆、柱子、神案、香爐會停住或沿著滑開，不會穿過去；走出大殿正門、穿過山門都順暢
- [ ] 蓮花池不能走進水裡，但可以從九曲拱橋走過去（走上橋時角色會站高一點）

**畫質（⚙️ 設定）**
- [ ] 自動模式顯示的等級合理（一般電腦應是「高」或「中」），旁邊的 FPS 數字大約多少：______
- [ ] 切到「低」畫面明顯變簡單但仍正常；切回「高」陰影與燈光恢復
- [ ] 玩五分鐘，畫面順不順：______

**聲音**（記得先點一下畫面，瀏覽器才允許出聲）
- [ ] 點香、擲筊、敲木魚、撞鐘、擊鼓都有聲音
- [ ] 走遠再敲木魚，聲音會變小
- [ ] 禪音背景音、靜音按鈕正常

**每日修行**
- [ ] 一開啟就跳出「每日簽到」通知，功德增加
- [ ] 頂部 🗓️ 紅色數字是 3，完成一項功課後變 2
- [ ] 隔天再開，連續天數變 2

**存檔**
- [ ] 護照 → 匯出存檔，下載到 JSON 檔
- [ ] 在另一個瀏覽器（或清除資料後）匯入，功德與分身都回來了

**安裝**
- [ ] 頂部出現「📲 安裝」或網址列有安裝圖示，安裝後從桌面開啟是全螢幕
- [ ] 關掉 `啟動神殿.bat` 的伺服器視窗，再從桌面開啟仍然能用（離線）

**AI 解籤**（有 Gemini API Key 才測）
- [ ] 設定填入 Key，求籤後按 AI 解籤，回覆完整沒有被截斷

## 二、手機（與電腦在同一個 WiFi）

**新增的參拜與大殿功能（電腦、手機各操作一次）**
- [ ] 右上參拜指引逐步前往七站，確實繞過香爐，途中結束會停步
- [ ] 拜墊可以跪坐，按 E／移動起身，同行也看得到
- [ ] 香油箱顯示目前功德與扣除數量，奉獻後餘額正確
- [ ] 籤詩櫃可以重閱先前求得的籤詩
- [ ] 匾額對聯與兩位護法可見，中央走道通暢

在電腦上用 `ipconfig` 查 IPv4 位址，手機瀏覽器開 `http://那個位址:8080`。Windows 防火牆若跳出詢問，要允許 Node.js 使用私人網路。
