# 神像參考圖提示詞

給 Codex 圖片生成用。流程：先畫正面圖（附 `mazu-front.png` 當風格參考）→ 確認後再畫側面與背面（附該尊正面圖）→ 用 TRELLIS 多圖轉 3D。
造型依 `scene/deities.js` 的遊戲設定。乖乖神像含真實品牌名，發布前確認授權前不畫。

## 共通要求（每張都加在最後）

```
- 風格：和附圖媽祖神像同一系列——台灣宮廟彩繪木雕神像，金漆與彩繪、細緻浮雕、溫潤質感，Q 版略帶圓潤的比例，莊嚴慈祥。
- 端坐在金色雕花寶座上（觀音例外，坐在蓮花座上），寶座下有金色長方形雕花底座。整體寬高比和附圖接近。
- 正交視角感、無透視變形，神像與寶座完整入鏡，不裁切。
- 純淺灰背景、柔和均勻光線、無陰影、無文字、無浮水印、無其他人物或道具。
- 直式構圖 1024x1536。
- 附圖只用來統一風格、比例與構圖，不要畫成媽祖，也不要沿用媽祖的冠飾、鳳凰與服飾。
```
